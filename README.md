# Zainab Mansour — Updated Resume Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling
- `script.js` — mobile menu, current year, and email contact form
- `ZainabCV_Updated.pdf` — updated CV
- `img/` — existing portfolio assets

## Deploy
Upload the contents of this folder to your Vercel/GitHub Pages project.

## Important
The contact form uses `mailto:` so no Web3Forms API key is exposed in the public source code.

If you prefer Web3Forms/Formspree later, add the provider key through the provider's recommended secure setup.
